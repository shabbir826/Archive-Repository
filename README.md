# Thesis Experiments Archive: Deep Learning for Financial Time-Series

This repository serves as an archive for the initial practice files, experimental datasets, and superseded code logs generated during my MS Computer Science thesis research.

# Research Overview
The core research focuses on evaluating and comparing various deep learning architectures against traditional statistical models for short-term Bitcoin price prediction. 

During the experimental phase, a baseline of strictly 24 forecasting models was evaluated. This archive contains the early implementations, draft accuracy rankings, and superseded iterations of these models, which include architectures such as Bi-LSTM, TimeXer, TimeMixer, and KOOPA, among others (note: the xLSTM architecture was excluded from the final experimental baseline).

# What's in this Repository?
 **Practice Datasets:** Early versions of the time-series data and preprocessing scripts used for initial model testing.
* **Superseded Code:** Initial training scripts and model architectures that have since been refined or replaced in the final project pipeline.
* **Experiment Logs:** Draft results and early-stage outputs kept for historical tracking and reference purposes.

# Important Note
This is a supplementary archive intended purely for record-keeping and tracking the experimental progress of the thesis. For the final, unified, and modular evaluation pipeline, please refer to the main project repository.
